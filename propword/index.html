How a prop record names a thingEvery number here is read out of the shipped Cythera Data 1.0.4 by Grimoire, where this block sits on every item’s page. This is the same block on its own, for the classes with combat fields.
A prop record names what it is with one 16-bit word: the prop type in the low ten bits, an aspect in the five above, so a step of aspect adds 1,024 and a step of type 1. Aspect n draws the type’s base tile + n and takes that tile’s name; what else it changes is the class script’s to say. The weapon classes read nothing per aspect, so a weapon at another aspect keeps its damage, reach and skill under the other tile’s picture and name. A second word holds Data1 and Data2, two bytes each class reads for its own purpose.
