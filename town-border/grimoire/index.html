Color cycling Water, lava and magic appear to move because the game cycles their colors in the palette, not because the picture changes. This setting controls that, and the walking and turning of sprites in the galleries. It does not affect something drawn from several frames, like a fountain, which is not palette cycling.
The font this page uses Cythera uses the font Argos A Nouveau, which the game keeps in its resource fork. The page reads it from whatever file you open and uses it unless you choose otherwise here. With no file open there is nothing to read it from, so the page uses Chicago, Susan Kare’s 1984 font for the Macintosh, recreated by Duane King. This page includes none of the game’s files to stand in for it.
Undither Cythera’s art uses dithering for a 256-color screen. This smooths the checkerboard patterns back into continuous shades. The result is an interpretation of the pixels, not the pixels themselves.

Grimoire

            
            
This site displays the data from the game Cythera (1999) in an interactive
              encyclopedic fashion. Opening it downloads its installer from archive.org, about
              28 MB, and keeps a copy in this browser. The copy can be cleared in
              Settings. While generative AI was used to help code this site, as much of the data
              displayed as possible is being read directly from the supplied file.

            
            
This site is intended as a resource for those who have already finished the game, spoilers abound!!

            
On the map: pinch or scroll to zoom, drag to move, tap a ring to
              go inside a tunnel or city, hover or hold on props or people for details.
